02 / Request lifecycle

Điều gì xảy ra khi gửi chat?

Thứ tự kiểm tra giúp xác định lỗi nhanh hơn: trước khi gọi Codex hay sau khi provider chạy.

REQUEST → RESPONSE

Đường đi của request

Chọn một bước để xem ý nghĩa của nó.

Ranh giới thực thi

Gateway đặt cấu hình cố định trước khi chạy model.

Sandbox: read-only

Agent không được ghi file theo policy này.

Tools bị tắt

Shell, unified exec, apps, plugins, computer use, multi-agent và web search.

Approval: never

Không có luồng xác nhận interactive; vì vậy chỉ nhận input từ caller tin cậy.

Giới hạn quan trọng: read-only hạn chế ghi, không phải cô lập quyền đọc dữ liệu trên máy.

03 / Persistence

Tách rành mạch dữ liệu cuộc chat qua gateway khỏi usage Codex đã có trên máy local.

LOCAL DATA

Gateway session

APP-OWNED

Phục vụ tiếp tục cuộc chat đã bắt đầu qua HTTP gateway.

  • FileDATA_DIR/sessions.json

  • LifecycleTTL mặc định 24h; lỗi/timeout sẽ xóa session để không resume history dang dở
  • Riêng tưCó lưu prompt/response trong messages

Native Codex usage

READ-ONLY SOURCE

Dashboard tổng hợp lịch sử Codex App/CLI cục bộ trên máy server.

  • NguồnNATIVE_CODEX_HOME → CODEX_HOME → ~/.codex
  • Đọcstate_5.sqlite và rollout JSONL
  • Lưu kết quảCác bảng native trong DATA_DIR/stats.sqlite
  • Riêng tưGiữ ID/project/model/time/usage; không giữ transcript text
Không tự sync giữa Mac và Windows

Video builds: video_builds + video_stages giữ metadata, scores và manifest version 1 trong SQLite hiện có. Session/turn scopes nối native events/turns, không sao chép token/cost/time. Transaction ngăn scopes chồng nhau; approved preview cắt usage tại thời điểm duyệt. Native session detail hiển thị tag Video/Stage. Đường dẫn preview/final chỉ là metadata.

Playground: nội dung chat chỉ giữ trong bộ nhớ tab; gửi lại context mỗi lượt và dùng Codex `--ephemeral`. Vì vậy native rollout collector không thấy usage của các thread này.

04 / Surface area

HTTP routes chính

OpenAI-like ở phần chat; endpoint dashboard dùng để quan sát gateway và Codex local.

HTTP
MethodPathÝ nghĩa
GET/healthHTTP status và active requests; không kiểm tra Codex login.
GET/v1/modelsDanh sách model gateway đưa ra.
POST/v1/chat/completionsChat stateless; dùng OpenAI client với local base URL.
POST/v1/sessionsTạo session metadata, chưa gọi model.
POST/v1/sessions/:id/messagesTiếp tục gateway thread, cố định model/reasoning.
POST/api/playground/chatDashboard chat cùng origin, Codex ephemeral.
GET/api/stats/*Thống kê riêng cho request đã qua gateway.
GET/api/native/overviewThống kê Codex App/CLI local trên máy server.
GET/api/videos[/:id]Video builds, timeline, manifest và so sánh model/engine/pipeline.
POST/PUT/api/videos[/import|/:id]Tạo/import hoặc cập nhật metadata JSON; X-Codex-Video: 1, Origin và Bearer checks hiện có.

Chạy và vận hành

npm start giữ terminal và log. npm start --silent -- -d chạy nền, bỏ output; npm stop dùng PID/ps trên macOS/Linux. PID khi spawn chưa xác nhận HTTP sẵn sàng.

Đọc hướng dẫn vận hành cho Node/npm, URL hiện tại và tình trạng port/proxy.
