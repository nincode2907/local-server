Workflow riêng

Owner/admin gửi stage events sau inference. Source client_reported, strict transitions, dedup, 60/phút,512/run,32stage. Label/message chỉ RAM, numeric metadata vào SQLite.

follow_workflow=1 tiếp tục stream sau inference; hết body replay vẫn trả metadata và đánh dấu partial. Stage timing là lúc gateway nhận báo cáo, không xác nhận tool đã thực thi.

Ownership và kết nối Docker

  • Admin key quản lý dashboard. App key chỉ xem và hủy run của chính app.
  • Bind mặc định 127.0.0.1. HOST và TRUSTED_HOSTS là cấu hình opt-in; non-loopback/extra hosts/app keys bắt buộc admin key.
  • Không mở wildcard Host hoặc CORS. App web dùng backend/BFF và fetch streaming với Bearer header; không đặt key trong URL hay bundle.

Đã kiểm chứng trên Docker Desktop máy này: container gọi host.docker.internal tới preview loopback, health 200, thiếu key 401 và SSE hoàn chỉnh. Topology Linux khác cần kiểm tra riêng.

Reconnect và giới hạn

Event có run ID, sequence, source và elapsed. Client dedup theo run/seq. Cursor hết hạn hoặc restart trả reset rõ ràng; metadata còn, output cũ không được tái tạo.

128 run trong RAM, tối đa 512 event / 1 MiB mỗi run, retention tối đa 10 phút từ lúc tạo; output hiện tại tối đa 1 MiB. 128 SSE connection, socket buffer tối đa 2 MiB; slow consumer bị đóng.
