So sánh trên cùng bài đo.

Codex, Ollama và LM Studio dùng chung run/event stream, với metric có nguồn và giới hạn rõ ràng.

Chọn model → chạy batch → đọc kết quả

Đối tượng đo

1–3 provider/model, ba prompt fixture cố định. Discovery chỉ đọc model có sẵn; không tải model hoặc đổi backend âm thầm.

Warmup và concurrency

Warmup tách khỏi các lượt đo. Queue/reject, lỗi, timeout và hủy vẫn được đếm. Cache/load state chưa được kiểm soát.

Kết quả và export

p50/p95, TTFO/TTFT, queue, actual token rate và success/terminal request/s. SSE cập nhật; JSON/CSV không prompt/output/credential.

Bounded execution

1 batch active,120request gồm warmup,131072requested local output-token allowance, concurrency≤8, time budget≤600giây. Daily reservation mặc định200request UTC, không refund khi cancel. Idempotency tránh tạo batch trùng.

Codex benchmark mặc định tắt; server opt-in và batch acknowledgement mới chạy. Tối đa10request/60giây, không hỗ trợ token cap/seed. Agent không gọi account thật để QA.

Cửa sổ throughput dùng monotonic clock, cohort gồm mọi lượt đo terminal; số sample unknown giữ riêng. Không tự unload/ép cold hoặc khẳng định warmup làm model warm.

Tài nguyên có scope

  • Gateway: Node delta CPU và RSS,100%=1core.
  • CLI/configured local PID: OS ps CPU average/RSS, process identity check; shared, không per-request.
  • Ollama model size/VRAM allocation từ backend nếu có; không phải GPU utilization.
  • Cloud inference/GPU không có sampler giữ unavailable, không lấy gateway RAM thay inference RAM.

Lưu metadata, giữ privacy

STRICT additive tables lab_batches/lab_daily, transaction quota và unique active/idempotency. Benchmark body ephemeral, Inspector không ghi body. Metadata giữ100batch/7ngày mặc định, bounded resource samples. Restart đánh dấu interrupted, không resume inference.

Origins local cấu hình phía server, exact hosts và redirect rejection; key backend riêng. Auth admin và same-origin guards cho Lab. Không wildcard CORS, không đổi Codex CLI isolation.
