Giữ terminal và log; Ctrl+C dừng server. Agent dùng chế độ có thể quan sát khi khởi động development server.

Chạy nền · theo yêu cầu người dùng

npm start --silent -- -d
npm stop

Trả prompt và bỏ output. -- truyền cờ cho script; --silent ẩn banner npm. PID nằm ở .local/server.pid.

PID được ghi lúc spawn, chưa xác nhận HTTP sẵn sàng. Nếu khởi động lỗi, foreground giúp đọc nguyên nhân. npm stop hiện xác minh process bằng ps trên macOS/Linux; chưa xác nhận hỗ trợ dừng nền trên Windows.

Dữ liệu có ba vòng đời

Defaults runtime là gpt-6-luna / low. `.env` trên máy tại thời điểm bootstrap đã ghi đè thành gpt-6.1-sol / medium.

Gateway session

DATA_DIR/sessions.json

Có messages để resume chat. Một process mỗi DATA_DIR; session JSON chưa có khóa giữa process.

Metrics và native usage

STATS_DB_PATH hoặc DATA_DIR/stats.sqlite

Metadata, usage và snapshot giá. Nguồn Codex chỉ được đọc; gateway và native usage là hai dataset riêng.

Playground giữ context trong bộ nhớ tab và chạy ephemeral. Reload xóa context. Native nguồn theo NATIVE_CODEX_HOME → CODEX_HOME → ~/.codex; Mac và Windows không tự sync. Không đưa token, auth hoặc transcripts vào diagnostics.

Port và proxy: trạng thái thực tế

Snapshot kiểm tra ngày 08/10/2026. Gateway bind loopback; hostname đã trả HTTP 200 qua Caddy IPv4. Browser automation không khả dụng trong phiên.

Thành phầnQuan sát / ranh giới
Server repoNode 24.21.0 nghe 127.0.0.1:15600. Mở dashboard trực tiếp.
Dev Hub registrydev-hub/projects.yml có sẵn; đã đăng ký codex-server, block 15600–15699, service web/API tại 15600.
CaddyDocker publish 127.0.0.1:80→80 trên IPv4 loopback. Caddy route codex-server.localhost → 127.0.0.1:15600 được quản lý trong marker Dev Hub.
Host / OriginGateway cho phép chính xác codex-server.localhost và các Host localhost/loopback hiện có; Origin vẫn same-origin, Bearer giữ nguyên.

Service dùng port 15600, trong block đã reserve. Gateway vẫn bind loopback. Proxy IPv4 loopback only. `curl --resolve` tới dashboard qua hostname trả HTTP 200; chưa kiểm tra giao diện trong browser.
