Từ source đến server

Chạy trong thư mục repo. Kiểm tra cả Node lẫn npm trước khi cài hoặc build.

01Chọn Node

nvm use
node -v / npm -v

02Cài dependencies

npm ci
Theo package-lock.

03Build

npm run build
Xuất vào dist/.

04Chạy và xác nhận

npm start
Kiểm tra /health.

Foreground · quan sát khi phát triển

npm run dev
# hoặc chạy bản đã build
npm start

Giữ terminal và log; Ctrl+C dừng server. Agent dùng chế độ có thể quan sát khi khởi động development server.

Chạy nền · theo yêu cầu người dùng

npm start --silent -- -d
npm stop

Trả prompt và bỏ output. -- truyền cờ cho script; --silent ẩn banner npm. PID nằm ở .local/server.pid.

PID được ghi lúc spawn, chưa xác nhận HTTP sẵn sàng. Nếu khởi động lỗi, foreground giúp đọc nguyên nhân. npm stop hiện xác minh process bằng ps trên macOS/Linux; chưa xác nhận hỗ trợ dừng nền trên Windows.

Dữ liệu có ba vòng đời

Defaults runtime là gpt-6-luna / low. `.env` trên máy tại thời điểm bootstrap đã ghi đè thành gpt-6.1-sol / medium.

Gateway session

DATA_DIR/sessions.json

Có messages để resume chat. Một process mỗi DATA_DIR; session JSON chưa có khóa giữa process.

Metrics và native usage

STATS_DB_PATH hoặc DATA_DIR/stats.sqlite

Metadata, usage và snapshot giá. Nguồn Codex chỉ được đọc; gateway và native usage là hai dataset riêng.

Playground giữ context trong bộ nhớ tab và chạy ephemeral. Reload xóa context. Native nguồn theo NATIVE_CODEX_HOME → CODEX_HOME → ~/.codex; Mac và Windows không tự sync. Không đưa token, auth hoặc transcripts vào diagnostics.

Port và proxy: trạng thái thực tế

Snapshot kiểm tra ngày 05/10/2026. Chưa công bố hostname proxy cho repo.

Thành phầnQuan sát / ranh giới
Server repoNode 24.21.0 nghe 127.0.0.1:4000. Mở dashboard trực tiếp.
Dev Hub registrydev-hub/projects.yml có sẵn; chưa có entry khớp đường dẫn codex-server. Chưa có block được cấp
CaddyĐang chạy với route dev/intelligence; chưa có route codex-server. Docker publish 0.0.0.0:80→80, không phải loopback-only; lsof không root thấy wildcard IPv6.
Host / OriginGateway chỉ nhận localhost/loopback; chưa chấp nhận hostname project .localhost. Không mở wildcard Host/CORS để bật proxy.

Giữ port 4000 theo endpoint người dùng đã chọn. Migration cần đọc registry, kiểm tra block/listener, đề xuất mapping cùng tương thích HTTP clients, rồi rà Host/Origin/Bearer và bind proxy. Xác minh HTTP IPv4/IPv6 và browser trước khi công bố hostname.
